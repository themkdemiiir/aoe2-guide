## 1. Patch Pulse — per-civ patch timeline (highest conviction)
**What:** `/civs/franks/changes` + `/patches/177723` pages: every balance change affecting a civ, per patch, generated by **diffing `aoe2techtree` `data/data.json` across its git history** (one snapshot per game update), with patch-note prose as annotation. Per-unit diffs fall out for free ("Knight line, last 5 patches").
**Why it wins:** Nobody does this. ageofnotes/wiki are chronological walls of text; techtree shows only "now". The June-2026 reality (Naval Overhaul, Last Chieftains) makes "what changed for my civ" a constantly recurring question. SEO: "{civ} changes update {N}" queries have zero good answers.
**Stack fit:** Pure build-time (clone techtree at pinned SHAs, diff JSON, emit content). Zero runtime cost. Reuses Epic 4's patch-currency pipeline — same sync scripts, one more output.
**Effort:** M (diff engine S, rendering S, patch-note linking M). **Depends on:** Epic 4 patch sweep.

## 2. Build-order trainer with bilingual audio (the flagship)
**What:** In-browser timed trainer over the existing 36 a pro player's build guide builds: play/pause clock, steps advance on schedule, **TTS audio cues (Web Speech API — EN and TR voices)**, keyboard space-bar/voice "next" for off-schedule play, adjustable speed (0.9×–1.2× for slower eco), end-of-run self-grade. PWA/offline so it works mid-LAN.
**Why it wins:** Cicero's trainer proves demand but lives in-game; buildorderguide is static text; AoE4 has audio apps, **AoE2 web has nothing with audio** — and a **Turkish audio build-order trainer exists nowhere on earth**. This is the feature that makes the bilingual angle a moat instead of a chore.
**Stack fit:** One Astro island, vanilla TS, `speechSynthesis` (free, on-device), build data already structured (steps have timings/villager counts). No backend.
**Effort:** M. **Depends on:** nothing — build data is ready today. Differentiates hard against aoe2.guide's "interactive" builds.

## 3. Share-cards (corrected after limit verification)
**Free-tier reality check (verified 2026-06-09):** Workers Free = 100,000 req/day, **10 ms CPU per invocation**, 3 MB compressed Worker size; KV Free = 100k reads / **1k writes** per day. Satori layout + resvg rasterization is pure CPU and routinely exceeds 10 ms, so **dynamic OG generation at the edge is NOT reliably feasible on the free plan**. The honest $0 split:

- **3a. Build-time OG images for every static page** (civs, builds, units): `satori` + `@resvg/resvg-js` (both MIT) run in **Node at build** — no runtime limits apply. One template, ~440 pages, Discord/Twitter embeds for the whole site. Effort S–M, depends on nothing.
- **3b. Player rating card as client-side download**: on the Epic-8 dashboard, render the card to a `<canvas>` in the browser and offer "Download card" (PNG via `canvas.toBlob`). Zero server CPU, fully free. Players share manually — not an auto-embed, and we say so.
- **3c. True dynamic `og:image` per player** requires Workers Paid ($5/mo) for the 30 s CPU budget — **out of scope under the $0 constraint**; revisit only if the project ever takes donations.

**Effort:** 3a = S–M now; 3b = S, **depends on** Epic 8.

## 4. Interactive counter web
**What:** Replace/augment the counters page with a zoomable counter-cycle graph (SVG, hand-rolled or d3-force at build): click a unit → its counters/countered-by light up, age toggle, links into unit pages. Feeds from `counters.json`.
**Why it wins:** Counter info exists everywhere as tables; a spatial cycle view is the way players actually think about it ("the triangle"). Pairs with Epic 5 polish for a signature visual.
**Stack fit:** Static SVG + one island. **Effort:** S–M. **Depends on:** counters.json localization (do TR strings first so the graph ships bilingual).

## Skip (researched, taken or wrong-fit)
- **Daily guessing game** — Agedle + AoE2Grid own it; a clone adds nothing. (A TR-only variant is the one angle left; park it.)
- **Civ draft tool** — aoe2cm is entrenched.
- **Tier list as a feature** — everyone has one; yours is a data-honesty fix (Epic 4), not a differentiator.
- **In-game overlay** — wrong platform for a website; Cicero/CaptureAge territory.

## Sequencing
Trainer (2) and Patch Pulse (1) are independent of Epic 8 and play to existing strengths. **The trainer is staged**: `docs/BUILD-ORDER-UX.md` items 1.3 (game-clock timer) + 1.4 (TTS read-aloud) ARE its stage 1 and ship as plain build-page UX — the full auto-paced trainer is just those two plus scheduling. Build-time OG (3a) is a standalone S-effort win anytime. Share-card download (3b) rides Epic 8. Counter web (4) is a polish-week project.
